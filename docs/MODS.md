# Optimization Mod Set

The default profile targets Minecraft `1.21.8` and Fabric. Versions are resolved at install time through Modrinth so the launcher can pick current compatible releases.

Core performance:

- `fabric-api`
- `sodium`
- `lithium`
- `ferrite-core`
- `immediatelyfast`
- `modernfix`
- `krypton`
- `c2me-fabric`
- `moreculling`
- `entityculling`
- `threadtweak`
- `memoryleakfix`

Quality and compatibility:

- `debugify`
- `reeses-sodium-options`
- `sodium-extra`
- `indium`
- `iris`
- `continuity`
- `enhanced-block-entities`
- `cull-less-leaves`
- `modmenu`
- `dynamic-fps`
- `no-chat-reports`

Bundled local mod:

- `ZonkOptimizer`

The launcher validates availability before download and falls back across nearby compatible game versions when a mod has not published an exact `1.21.8` build.
